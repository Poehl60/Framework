SECTION ONE -- METHOD
==========================================================================


BASIC QUALITIES OF COHERENCE
------------------------------
Eight qualities. Mutually dependent.

INTERNAL CYCLE PROPERTIES [Q1-Q4]

  1. GENERATIVE CYCLE
     Completes a loop: takes in, transforms, returns.
     Failure mode: cycle collapse or performance without function.

  2. SURPLUS PRODUCTION
     Outputs exceed cost of running the cycle across an honest window.
     Moral content lives here.
     Failure mode: consumption dominance.

  3. CORRECTION CAPACITY
     Detects contradiction between outputs and orientation.
     Moves without external pressure.
     Failure mode: correction absence or capture.

  4. GENUINE AXIS
     Orientation generated internally with self-examination present.
     Failure mode: imposed axis.

BOUNDARY PROPERTIES [Q5-Q6]

  5. BOUNDARY INTEGRITY
     Honest definition of who is inside the boundary.
     Does not shift to exclude populations experiencing harm.
     Failure mode: boundary manipulation.
     Linked to Q7 -- boundary drift is a measurement integrity failure.

  6. PROPORTIONAL RESPONSE
     Correction force proportional to deviation detected, not to the
     threat correction poses to existing power.
     Failure mode: overcorrection as suppression.

TEMPORAL PROPERTIES [Q7-Q8]

  7. MEASUREMENT INTEGRITY
     System maintains honest, accessible surface by which outputs can
     be evaluated against stated orientation. Includes boundary honesty,
     signal sequencing, correction trigger accessibility.
     Failure mode: measurement surface captured, drifted, or destroyed.
     Most load-bearing quality -- Q1-Q6 intact with Q7 destroyed
     misreads as Variable or High while consuming.
     Correction pathway: surface reconstruction, not cycle repair.
     Primary proof: Enron [deployed]. Doctor Manhattan [structural].

  8. TRANSMISSION SELECTIVITY
     System transmits correctable axis to successors, not locked state.
     Fidelity necessary but insufficient.
     Failure mode: Fertile Lock.
     Q4 = within-window axis integrity. Q8 = what crosses transmission
     boundary.
     Primary proof: Faeanor -> sons [Q4/Q8 distinction clearest case].

STRUCTURAL ORDER

  Generative cycle         precondition
  Surplus production       moral value lives here
  Correction capacity      keeps cycle honest
  Genuine axis             gives correction direction
  Boundary integrity       keeps measurement population honest
  Proportional response    keeps correction from becoming next failure
  Measurement integrity    keeps correction capacity functional
  Transmission selectivity what coherence produces across time

ANTI-COHERENCE REVERSE ORDER

  Fertile Lock -> Measurement destruction -> Boundary manipulation
  -> Axis imposition -> Correction capture -> Consumption dominance
  -> Cycle collapse

  Q6 failure runs parallel, not sequential.


--------------------------------------------------------------------------
GOALS
--------------------------------------------------------------------------

  1. Accurate measurement of generating versus consuming across defined
     population and time window. Named parameters before measurement:
     boundary, population, window, substrate.
  2. Identification of failure mechanism, not just failure presence.
     Each failure state has a different correction pathway.
  3. Practical utility. If a component does not produce a reading more
     useful than intuition alone, it does not belong.


--------------------------------------------------------------------------
VALUES
--------------------------------------------------------------------------

  GOOD = material security + reduced coercive exposure + expanded
         options. Named population, defined boundary, honest window.
         Trackable from outputs without access to internal states.

  BAD  = transfers that increase coercive exposure, reduce material
         security, or narrow options -- regardless of intent.
         Intent = mechanism evidence only.

Framework does not initiate critical harm in response to Low coherence.
Response = minimum necessary, contextual, measured from outputs.


--------------------------------------------------------------------------
COHERENCE WEAPON TEST
--------------------------------------------------------------------------

Asks: is this system being used as a weapon against coherence rather
than as an expression of it? Applied first in any measurement.

SCORING PROCEDURE

  Irrelevant weapons exit pool entirely -- do not score zero.
  Weapon clearly present = full percentage value.
  Close match = half value.
  Not relevant = exits pool.

  Final score = sum of scored values / sum of relevant pool total.
  High = bad. Low = good.
  Zero = none present OR none relevant -- distinction noted in report.

DEPLOYMENT DIRECTION

  Defensive [protecting genuine coherence] = noted, not scored.
  Aggressive [suppressing measurement of own extraction] = scores.
  Direction determined by net transfer reading, not stated intent.

MEASUREMENT DIFFICULTY PRINCIPLE

  Genuine unknowing = calibration problem [T1/T2]. Does not score.
  Known concealment where operator benefits = Q7 weapon. Scores.
  Test: does system controlling complexity benefit from unreadability?
  Operator cannot claim genuine unknowing if they benefit from it.

SCALE AND TIMESCALE NOTE

  Large institutions show high weapon deployment regardless of coherence
  level. Diagnostic question: proportion defensive vs aggressive in
  specific window. Short window most reliable.

SECTION TWO -- MEASUREMENT
==========================================================================


BOUNDARY SELECTION [precedes all other parameters]

Three constraints in sequence before measurement begins:

  1. Harm exclusion -- no boundary excluding populations currently
     bearing costs of system operation.
  2. Extraction exclusion -- no boundary excluding populations whose
     resources are being consumed.
  3. Coherence measurement runs only after boundary passes both filters.

Boundary selection = value selection. Prevents circularity.
Proof cases: Shareholder Primacy [fails 1+2, rejected], Bell Labs
AT&T boundary [passes both, measurement proceeds].

Political cases: full moral boundary forced. Both boundary readings
run explicitly. See Section Four.


PARAMETERS [after boundary selection]

  Population / Window / Method / Substrate
  Missing any = Variable by default.

Output states: None / Low / Middle / Variable / High / State
Middle requires substrate specification or returns Variable.


MEASUREMENT RULES

  - Legitimacy and morality = parallel tracks, measured separately.
  - Intent = mechanism evidence only. Does not modify output reading.
  - Population groups measured separately, not aggregated.
  - Past novel-input responses = most reliable evidence within window.
  - Net transfer direction distinguishes parasitic from mutualistic.
    Volume secondary to direction.
  - Individual actor properties = mechanism evidence only.
  - Measurement difficulty from genuine unknowing = calibration problem.
    From known concealment where operator benefits = Q7 weapon active.


--------------------------------------------------------------------------
THREE-AXIS MEASUREMENT
--------------------------------------------------------------------------

  COHERENCE AXIS [horizontal]
    Cycle integrity across all eight qualities.
    Left = anti-coherence. Right = coherence. Independent of moral
    direction.

  GENERATION AXIS [vertical]
    Up = positive generation for unit and surrounding units.
    Down = extraction from unit and surrounding units.

  CAPTURE AXIS [depth]
    Front [Low]   Friction at boundary, correction capacity intact.
    Mid   [Mild]  Selective deviation suppression internalized.
    Back  [High]  Axis shifted below self-examination depth.

Coherence + generation = what the system is doing.
Capture = under whose orientation.

CRITICAL CONFIGURATION
  High coherence + positive generation + High capture = most dangerous.
  Outputs look genuine; axis belongs to external party.

Internal capture signature: differential contestation cost by group,
selective deviation suppression by group, surplus flowing consistently
from one group position toward another.

Captured systems are almost always run by people who believe they are
not captured. Structural property, not moral judgment.


--------------------------------------------------------------------------
STATE MEASUREMENT PROCEDURE
--------------------------------------------------------------------------

Four tests in sequence. Wrong correction accelerates failure.

  TEST ONE   Contestation Cost Asymmetry -- most accessible. No stress
             event required. Identifies capture presence and location.
  TEST TWO   Transfer Direction -- net surplus flow, short window.
  TEST THREE Correction Initiation -- self-correct before external
             pressure? Historical reconstruction preferred.
  TEST FOUR  Directionality Composite.

FAILURE MODE IDENTIFICATION

  Asymmetric + extractive  + correction absent   = Captured state
  Asymmetric + generative  + correction present  = Contained /
                                                   developmental gap
  Symmetric  + extractive  + correction absent   = Axis-Lock
  Symmetric  + extractive  + correction present  = Consumption failure
  Symmetric  + generative  + correction present  = Functional
                                                   [check directionality]
  Q1-Q6 intact + extractive + surface fabricated = Measurement Collapse
  High fidelity transmission + locked axis       = Fertile Lock

DIRECTIONALITY COMPOSITE
--------------------------------------------------------------------------

Four signatures, equal weight, independent.

  S1  Novel input response
      1 = integrates genuinely novel inputs requiring axis adjustment.
      0.5 = evidence present, condition compromised. 0 = inaccessible.
      Operational procedure: present system with input that contradicts
      current axis. Genuine integration = axis revision visible in
      subsequent behavior. Recombination = input explained using existing
      axis without axis movement. Score 0 if axis does not move despite
      genuine contradiction. Historical reconstruction preferred.
      Ambiguous [input absorbed, axis movement unclear] = 0.5.

  S2  Scarcity behavior
      1 = axis holds under resource drop without external supply.
      0.5 = partial evidence. 0 = inaccessible.

  S3  Correction initiation
      1 = corrections happen before external pressure arrives.
      0.5 = timing ambiguous or observer effect. 0 = inaccessible.
      Operational procedure: identify earliest documented correction
      signal. Reconstruct timeline of external pressure relative to it.
      Correction precedes pressure = score 1. Pressure predates
      correction = score 0. Ambiguous or undocumented = 0.5. Bias
      toward 0.5 when uncertain -- external pressure often arrives
      before becoming visible.

      1 = cost consistent across group positions inside boundary.
      0.5 = partial data. 0 = inaccessible.

  T1 [resolvable]

    Structurally indeterminate. Not a measurement failure.

    T2 IS A NAMED STATE, NOT A FAILED READING.

    SUBTYPE A -- Concealment [reveal type]
      One axis operative, concealment active. Stress reveals.
      Four indirect discriminating tests [weighted]:
        - Resource directionality inconsistent with stated axis
        - Asymmetric information protection under minor pressure
        - Behavioral consistency higher than variability predicts
        - Low-stakes activation consistent with one candidate axis
      PRIMARY: Miquella [Elden Ring].

    SUBTYPE B -- Variability [select type]

      Indicators: no concealment cost pattern, genuine axis variation
      by context, low-stakes activation switches between candidates.
      PRIMARY: Macbeth [Shakespeare].

      "T2 Pre-resolution. [Subtype: A/B, confidence: low/medium.]
       If stress resolves toward [X]: trajectory A.
       If toward [Y]: trajectory B.
       Pre-stress indicators: [weighted list]."

  T3 [unreachable]
    Framework cannot calibrate own axis from inside own operation.
    Applies to framework itself and to analysts with strong priors --
    especially in political cases.

  T4 [structural obscuration]
    Net transfer direction is systematically the thing most obscured
    by weapon deployment. Structural, not a calibration problem.

  T5 [pre-measurement states]
    States that are productive, stable, and non-damaging but
    structurally prior to the conditions measurement requires.
    Not failure states. Not T2, T3, or T4. Measurement surface is
    suspended or undefined by the nature of the state itself --
    forcing measurement onto these states disrupts them.

    Examples: flow states, genuine rest, pre-reflective skill
    execution, deep creative process.

    Common property: productivity depends on measurement surface
    being temporarily suspended. States resolve naturally -- not
    permanent.

    MEASUREMENT PAUSE AND RESUMPTION PROTOCOL
    Before entering a T5 state, name:
      - What observable output or time boundary triggers resumption.
      - What window the post-T5 measurement will cover.
    Measurement pauses at entry. Resumes at defined condition.
    State remains undisturbed; framework picks up where it left off.

    T5 is a scheduled pause with defined resumption criteria, not
    a gap in the framework. Accurate measurement is useful -- it
    can stop and start within a defined context without losing
    validity. Forcing measurement before resumption condition is
    met is an intervention, not an observation.

SECTION THREE -- THEORY
==========================================================================


The Coherence Complex analyzes how systems maintain or lose internal
integrity over time, what distinguishes genuine function from performed
function, and how failure of large systems relates to failure of
individual units composing them. One structured way of looking at these
problems. Conclusions follow from structure and cases tested.

Makes visible: net transfer direction, presence or absence of genuine
correction capacity, genuinely set vs imposed axis. T3 = where the
framework cannot see itself clearly -- real, and not resolvable from
inside its own operation.

INTELLECTUAL HISTORY

Geometric intuition [torus, dynamic equilibrium] from physical systems.
Moral substrate [generating vs extracting, visible in outputs] from
historical cases. Capture axis [structural not moral failure] from
asking why intelligent sincere people run systems producing bad outputs.
Q7 [coherence without measurement is axis-lock with good aesthetics]
from recognizing the measurement surface is what makes correction
possible. Q8 [fidelity is not correctability] from Bell Labs breakup
and Faeanor -- high-quality transmission producing locked successors.

Theory is not finished because the case library is not finished. Some
conditions will require the framework to change rather than the case
to be forced into existing categories. That process is the correction
mechanism working.

Use as a tool for seeing more clearly, not an authority for
conclusions. When framework reading conflicts with other evidence,
both deserve examination.

MOST IMPORTANT CLAIM
  Failure is coherence doing the wrong thing, not coherence being
  absent.

EVOLUTIONARY COHERENCE PRINCIPLE
  Coherence infrastructure not actively load-bearing is lost through
  surplus economics, not capture. Correction mechanism requires active
  use. Dynamic equilibrium between coherence and anti-coherence is the
  generative condition. Torus model: stability through movement.
  Static torus is not stable.

SCALING LIMITS [empirical finding -- not derivable from eight qualities]
  Larger institutions across longer timescales show higher weapon
  deployment regardless of coherence level. Probable mechanism: Q8
  Fertile Lock drift accumulating across transmission events. No clean
  solution found. Mondragon ownership-transmission model is best
  observed resistance case.

DIVINE FREEDOM NOTE
  If coherence is the generative condition and anti-coherence is viable
  -- the gap between mechanics rewarding coherence and enforcement of
  coherence is freedom. Anti-coherence is not a design flaw; it is the
  space that makes genuine choice possible. Fully examined anti-coherence
  chosen freely reads as High Q4 even with extractive direction.
  Both the freedom and the cost are real simultaneously.
  PRIMARY case: Judge Holden [Blood Meridian]. Examined proof:
  Eren Yeager post-inversion [Attack on Titan].

COHERENCE TYPE STRUCTURAL DISTINCTION

  Types split more usefully by whether extraction requires corrupting
  the structure than by inherent productive/damaging nature.

  Extraction requires corrupting the structure [repairable]:
    Family, Science, Signal, Relational, Intrinsic Loose, Combined,
    Silent Alternative. All have generative and consuming variants.
    Type describes architecture; axis and capture readings describe
    direction. Corruption is detectable because the structure has a
    generative baseline to measure against.
    Correction pathway: axis intervention or capture removal.

  Extraction is the structure [not redirectable]:
    Extractive Intrinsic. Extraction is the constitutive axis. No
    generative mechanism to restore. Cannot be redirected without
    destroying it entirely. Repair is not the correct intervention --
    only containment or dissolution.
    Correction pathway: topology-level response, not unit-level repair.

  Practical implication: identifying which category applies before
  attempting correction prevents applying unit-level repair to a
  structure where extraction is constitutive -- which accelerates
  consumption rather than correcting it.


ANTI-COHERENCE AND DAMAGE AS SEPARATE MEASUREMENTS

  Anti-coherence is a measurement of direction relative to a named
  system. Damage is a separate measurement of output effect on a named
  population. These are parallel tracks and must not be conflated.

  A system can read as anti-coherent relative to one topology while
  producing no damage -- or net positive output -- to the population
  that topology was consuming. The framework's boundary selection rule
  determines which reading applies. Anti-coherence relative to an
  extractive system is not the same as anti-coherence relative to a
  generative one.

  Three cases where anti-coherence reads without usual damage:

  Refusing to perpetuate a consuming cycle
    Anti-coherent relative to the system requiring perpetuation.
    No damage to populations -- the cycle refused is the extractive one.
    PRIMARY: Lothric [Dark Souls 3 -- refusal to link the fire].

  Operating against commercial extraction topology
    Anti-coherent relative to standard commercial output logic.
    No consumption of surrounding units -- only prior output consumed.
    PRIMARY: Death Grips [destroying working configurations before
    extraction completes].

  Coherent Exit from consuming topology
    Anti-coherent relative to any system expecting continued
    participation. Net generative effect on surrounding topology
    after departure.
    PRIMARY: Historical Buddha [renunciation reads as anti-coherent
    by Vedic social topology; surrounding topology net positive].

  Formal rule: anti-coherence reading requires named reference system.
  Damage reading requires named population. Neither reading implies
  the other. A system anti-coherent relative to an extractive topology
  may be the most coherent thing operating in that topology from the
  perspective of the extracted population.

OUROBOROS [symbol and topology]
--------------------------------

  Type: Primary [topology note]
  Proof for: Closed self-sustaining consumption loop as distinct
  topology; boundary between input and output collapsed

  Self-consuming cycle that sustains itself through its own
  consumption. Appears across cultures independently [Egyptian,
  Greek, Norse, alchemical] -- archetypal pattern not single source.

  Framework reading: distinct from other closed loops in library.
  Idea of Evil [Berserk] -- external population as substrate.
  Gravemind -- external systems as substrate.
  Ouroboros -- consumes itself. No external substrate required.

  Key property: self-sustaining consumption. Loop doesn't require
  external input to continue -- feeds on own outputs. Stable in a
  way other consuming systems are not, but finite because it
  processes itself down over time.

  Framework gap: Q1 [cycle] runs; Q2 [surplus] is undefined because
  boundary between input and output collapses. Standard measurement
  assumes systems consume external substrate or generate for external
  populations. Ouroboros does neither cleanly.

  Named as distinct topology type: Closed Self-Sustaining Loop.
  Neither generative nor consuming relative to external populations.
  Inherently finite -- processes itself down regardless of apparent
  stability.

  Fictional proof cases:

    Iwagakure [Hell's Paradise] -- partial, with external substrate.
    Old One cycle [Demon Souls] -- cosmological scale.
  Real-world analog: debt-based monetary systems with interest
  compounding faster than underlying surplus generation [pending
  full protocol -- WIP item 13].

SECTION FIVE -- POLITICAL MEASUREMENT
==========================================================================

The framework tool is neutral. Political measurement is not and cannot
be. This section states its value foundation explicitly rather than
claiming false neutrality.

FOUNDING VALUES FOR POLITICAL MEASUREMENT

  Autonomy as primary axis: people can do what they want.
  Honesty as constraint: outputs must be honest about what is being
  done and who bears the cost.

  These two values together produce a stricter standard than most
  political ideologies apply. Autonomy without honesty is concealment.
  Honesty without autonomy is coercion. Both are required.

  Where autonomy conflicts with extraction: when what someone wants
  extracts from others who didn't consent, the autonomy claim forecloses
  measurement of the extraction. Honesty resolves this -- you can do
  what you want as long as you are honest about what you are doing and
  who bears the cost. Concealed extraction violates the honesty
  constraint regardless of whether autonomy is cited as justification.

IDEOLOGY VS POLITICS

  Ideology = application of moral values in structured form. Honest
  about what it is. Contestable at values level and application level.

  Politics = frequently uses ideological framing while deploying weapons
  to force boundary outcomes. The dishonesty is the gap between stated
  values and actual boundary manipulation. Not all politics operates
  this way -- but the framework measures the gap where it exists.

  Political measurement is necessary precisely because politics is not
  honest by nature. The tool applies where honesty is absent.

  Analyst bias probable throughout. All readings contested and

  Independent review recommended before use as confirmed readings.
  The founding values stated above are the analyst's own -- they

HIGH-USE POLITICAL WEAPONS AND COUNTERMEASURES
--------------------------------------------------------------------------

Most deployed political weapons with measurement countermeasures.
Countermeasures are not rebuttals -- they are tools for reaching an
honest output reading despite weapon deployment.

  Martyrdom Laundering [Q8]
    Past suffering used as permanent foreclosure on present output
    measurement. Highly effective because the suffering is genuine --
    the weapon exploits real history.
    Countermeasure: window isolation. Separate historical legitimacy
    claims from current output readings explicitly. Both can be true
    simultaneously -- historical suffering real AND current extraction
    measurable. Neither forecloses the other. Run separate readings
    per window; do not allow long-window moral weight to suppress
    short-window output measurement.

  Security Framing [Q7]
    Measurement attempts made readable as threats to collective safety.
    Effective because genuine security concerns exist alongside
    manufactured ones.
    Countermeasure: identify who benefits from measurement being
    suppressed. Genuine security concerns survive output measurement
    -- they produce observable threats with measurable responses.
    Fabricated security concerns require suppressing measurement to
    maintain. The beneficiary check [protocol test 9] is the
    discriminating tool.

  Necessity Escalation [Q6]
    Each action justified by prior; original claim never re-examined.
    Effective because each individual step appears proportional.
    Countermeasure: trace back to founding claim and measure it
    independently of all subsequent steps. If founding claim does not
    survive scrutiny, the chain has no anchor. Run the founding claim
    through the irreversibility test [protocol test 1] independently.

  Universalism Trap [Q5]
    Particular group's interest framed as universal. Contestation
    appears as opposition to universalism itself.
    Countermeasure: name the specific population that would benefit
    most if the "universal" policy were implemented. Universal claims
    with identifiable primary beneficiaries are particular interests
    in universal framing. Apply boundary selection rule -- who is
    actually inside the measurement boundary?

  Contamination Framing [Q5]
    Legitimate measurement associated with condemned positions.
    Measurement suppressed by associating the measurer with a
    discredited group or position.
    Countermeasure: separate the measurement from the measurer
    completely. Output readings are valid or invalid based on the
    evidence they rest on, not the identity or position of who
    produces them. Run counterfactual test [protocol test 3] -- would
    the same output reading be acceptable if produced by someone the
    audience approved of?

  Obligation Manufacture via Moral Debt [Q7]
    Genuine historical relationship or suffering converted into
    asymmetric obligation that forecloses present measurement.
    Countermeasure: name the specific obligation claimed, its origin,
    and who benefits from its application. Genuine obligations are
    symmetrical -- they apply consistently across comparable cases.
    Obligations that apply only when they benefit a specific party
    are Obligation Manufacture not genuine moral weight.

  Boundary Manipulation [Q5]
    Shifting who counts as inside the measurement boundary to exclude
    populations currently experiencing harm.
    Countermeasure: apply harm exclusion constraint [boundary selection
    rule] before any other measurement. No boundary that excludes
    populations currently bearing costs of system operation. Boundary
    manipulation is detectable because it requires actively excluding
    the harmed population -- the exclusion mechanism is visible even
    when the harm is not.

--------------------------------------------------------------------------
POLITICAL MEASUREMENT PROTOCOL
--------------------------------------------------------------------------

All 11 tests required for confirmed reading. Partial protocol =
lower confidence rating. No political reading reaches confirmed
without adversarial reading produced and prediction stated.

  1.  IRREVERSIBILITY TEST
      Identify who bears irreversible harm [death, displacement,
      generational damage] before readings begin. Irreversible harm
      carries higher evidentiary weight than reversible extraction.
      State finding explicitly before any other measurement proceeds.

  2.  CONSISTENCY TEST
      Apply identical standard regardless of which population is
      favored. If a weapon scores against one state, identical
      deployment by an allied or sympathized state scores equally.
      No exemptions by sympathy or prior relationship.

  3.  COUNTERFACTUAL TEST
      Would reading change if populations were swapped? If yes --
      reading is tracking group identity not outputs. T3 active.
      Flag and revise before proceeding.

  4.  CORRECTION CAPACITY TEST
      Does system tolerate internal contestation of its own outputs?
      Distinguish Selection Pressure [capacity present but unused]
      from Axis-Lock [capacity eliminated]. Different failure states,
      different correction pathways.

  5.  WINDOW SPLIT TEST
      Run short window [current policy] and long window [institutional
      patterns] explicitly. Both required. Gap between them is
      diagnostic. State which window produces which reading and why.

  6.  ANALYST PRIOR TEST
      State expected conclusion before reading begins. If reading
      matches prior -- run tests 2 and 3 again with extra scrutiny.
      Framework should occasionally surprise the analyst. If it never
      does, T3 is operating and readings are confirmation not
      measurement.

  7.  ADVERSARIAL READING
      Produce the strongest honest case for the opposite conclusion.
      Cannot steelman adequately = reading is uncontested not
      confirmed. Uncontested is not the same as correct.

  8.  THIRD POPULATION TEST
      Identify a population with no stake in the system being measured.
      Run reading from their perspective. If reading changes
      significantly -- prior readings are more boundary-dependent than
      accounted for.

  9.  WEAPON BENEFICIARY CHECK
      For every weapon identified, name the specific concrete
      beneficiary of its deployment. Vague beneficiary = weapon exits
      pool. Cannot name who benefits = probable pattern-matching not
      evidence.

  10. PREDICTION TEST
      State a falsifiable prediction based on the reading. If nothing
      the system could do would change the reading -- unfalsifiable,
      not a measurement. Absence of this test is itself a diagnostic
      signal. Most political analysis never attempts this test.

  11. ANTI-POLITICS TEST
      Run the external actor boundary check [see above]. Name any
      external actors shaping boundary outcomes for populations they
      bear no cost from. If present -- note as structural weapon
      deployment regardless of other readings.
