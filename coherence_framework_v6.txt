BASIC QUALITIES OF COHERENCE
------------------------------
Eight qualities. Mutually dependent -- missing one is a specific failure
mode at that quality, not a general coherence failure.

INTERNAL CYCLE PROPERTIES [Q1-Q4]

  1. GENERATIVE CYCLE
     Completes a loop: takes in, transforms, returns.
     Failure mode: cycle collapse or performance of cycle without
     function.

  2. SURPLUS PRODUCTION
     Outputs exceed cost of running the cycle across an honest window.
     Moral content lives here.
     Failure mode: consumption dominance.

  3. CORRECTION CAPACITY
     Detects contradiction between outputs and orientation.
     Moves without external pressure.
     Failure mode: correction absence or capture.

  4. GENUINE AXIS
     Orientation generated internally with self-examination present.
     Failure mode: imposed axis.

BOUNDARY PROPERTIES [Q5-Q6]

  5. BOUNDARY INTEGRITY
     Honest definition of who is inside the boundary.
     Does not shift to exclude populations experiencing harm.
     Failure mode: boundary manipulation.
     Note: linked to Q7 -- boundary drift is a measurement integrity
     failure as much as a boundary failure.

  6. PROPORTIONAL RESPONSE
     Correction force proportional to deviation detected -- not to the
     threat that correction poses to existing power.
     Failure mode: overcorrection as suppression.

TEMPORAL PROPERTIES [Q7-Q8]

  7. MEASUREMENT INTEGRITY
     System maintains an honest, accessible surface by which its own
     outputs can be evaluated against its stated orientation. Includes
     boundary honesty, signal sequencing, correction trigger
     accessibility.
     Failure mode: measurement surface captured, drifted, or destroyed.
     Most load-bearing quality -- Q1-Q6 intact with Q7 destroyed
     misreads as Variable or High while consuming.
     Correction pathway: surface reconstruction, not cycle repair.
     Proof cases: Doctor Manhattan [structural], Enron [deployed],
     Catholic Church abuse crisis [deployed].

  8. TRANSMISSION SELECTIVITY
     System transmits correctable axis to successors -- not locked state.
     Fidelity necessary but insufficient.
     Failure mode: Fertile Lock.
     Note: Q4 = within-window axis integrity. Q8 = what crosses
     transmission boundary.
     Proof cases: F?anor ? sons [primary], Word Bearers, Mont P?lerin.

STRUCTURAL ORDER

  Generative cycle         precondition
  Surplus production       moral value lives here
  Correction capacity      keeps the cycle honest
  Genuine axis             gives correction direction
  Boundary integrity       keeps measurement population honest
  Proportional response    keeps correction from becoming next failure
  Measurement integrity    keeps correction capacity functional
  Transmission selectivity what coherence produces across time

ANTI-COHERENCE REVERSE ORDER

  Fertile Lock [Q8] ? Measurement destruction ? Boundary manipulation
  ? Axis imposition ? Correction capture ? Consumption dominance ?
  Cycle collapse [Q1]

  Note: Q6 failure runs parallel, not sequential.


--------------------------------------------------------------------------
GOALS
--------------------------------------------------------------------------

  1. Accurate measurement of generating versus consuming across defined
     population and time window. Named parameters before measurement
     begins: boundary, population, window, substrate.
  2. Identification of failure mechanism -- not just failure presence.
  3. Practical utility. If a component does not produce a reading more
     useful than intuition alone, it does not belong.


--------------------------------------------------------------------------
VALUES
--------------------------------------------------------------------------

  GOOD  =  material security + reduced coercive exposure + expanded
            options. Named population groups, defined relational
            boundary, honest window. Trackable from outputs.

  BAD   =  transfers that increase coercive exposure, reduce material
            security, or narrow options -- regardless of intent.
            Intent = mechanism evidence only.

Framework does not initiate critical harm in response to Low coherence.
Response to critical harm = minimum necessary, contextual, measured
from outputs.


--------------------------------------------------------------------------
COHERENCE WEAPON TEST
--------------------------------------------------------------------------

Asks: is this system being used as a weapon against coherence rather
than as an expression of it? Applied first in any measurement.

SCORING PROCEDURE

  - Irrelevant weapons exit pool entirely -- do not score zero.
  - Weapon clearly present    = full percentage value
  - Close match               = half value
  - Not relevant              = exits pool

  Final score = sum of scored values / sum of relevant pool total.
  High = bad. Low = good. Zero = none present OR none relevant --
  distinction noted in report.

DEPLOYMENT DIRECTION

  Defensive  [protecting genuine coherence] = noted, not scored.
  Aggressive [suppressing measurement of own extraction] = scores.
  Direction determined by net transfer reading, not stated intent.

MEASUREMENT DIFFICULTY PRINCIPLE

  Genuine unknowing = calibration problem [T1/T2]. Does not score.
  Known concealment where operator benefits = Q7 weapon. Scores.
  Test: does system controlling complexity benefit from unreadability?
  Operator cannot claim genuine unknowing if they benefit.

SCALE AND TIMESCALE NOTE

  Large institutions expected to show high weapon deployment regardless
  of coherence level. Diagnostic question: proportion defensive versus
  aggressive in specific window. Short window most reliable for
  detection.

SECTION TWO -- MEASUREMENT
==========================================================================


BOUNDARY SELECTION [precedes all other parameters]

Three constraints applied in sequence:

  1. Harm exclusion -- no boundary excluding populations currently
     bearing costs of system operation.
  2. Extraction exclusion -- no boundary excluding populations whose
     resources are being consumed.
  3. Coherence measurement runs only after boundary passes both.

Boundary selection = value selection. Prevents circularity.

Proof cases: Shareholder Primacy [fails 1+2, rejected], Westeros
noble boundary [fails both, rejected], Bell Labs [passes both,
measurement proceeds].

POLITICAL CASES: full moral boundary forced. Both boundary readings
run explicitly. See Political Cases section.


PARAMETERS [after boundary selection]

  Population / Window / Method / Substrate
  Missing any = Variable by default.

Output states: None / Low / Middle / Variable / High / State
Middle requires substrate specification or returns Variable.


MEASUREMENT RULES

  - Legitimacy and morality = parallel tracks, measured separately.
  - Intent = mechanism evidence only.
  - Population groups measured separately, not aggregated.
  - Past novel-input responses = most reliable evidence within window.
  - Net transfer direction distinguishes parasitic from mutualistic.
    Volume secondary to direction.
  - Individual actor properties = mechanism evidence only.
  - Measurement difficulty from genuine unknowing = calibration
    problem. From known concealment where operator benefits = Q7.


--------------------------------------------------------------------------
THREE-AXIS MEASUREMENT
--------------------------------------------------------------------------

  COHERENCE AXIS [horizontal]
    Cycle integrity across all eight qualities.
    Left = anti-coherence. Right = coherence.
    Independent of moral direction.

  GENERATION AXIS [vertical]
    Up = positive generation for unit and surrounding units.
    Down = extraction from unit and surrounding units.

  CAPTURE AXIS [depth]
    Front [Low]   Friction at boundary, correction capacity intact.
    Mid   [Mild]  Selective deviation suppression internalized.
    Back  [High]  Axis shifted below self-examination depth.

Three-axis: coherence + generation = what system is doing. Capture =
under whose orientation.

CRITICAL CONFIGURATION
  High coherence + positive generation + High capture = most
  dangerous. Outputs look genuine while axis belongs to external party.

Internal capture signature: differential contestation cost by group,
selective deviation suppression by group, consistent surplus flow
from one group position toward another.

Captured systems almost always run by people who believe they are
not captured. Structural property, not moral judgment.


--------------------------------------------------------------------------
STATE MEASUREMENT PROCEDURE
--------------------------------------------------------------------------

Four tests in sequence. Wrong correction accelerates failure.

  TEST ONE   Contestation Cost Asymmetry -- most accessible, no stress
             event required. Identifies capture presence and location.
  TEST TWO   Transfer Direction -- net surplus flow, short window.
  TEST THREE Correction Initiation -- self-correct before external
             pressure? Historical reconstruction preferred.
  TEST FOUR  Directionality Composite.

FAILURE MODE IDENTIFICATION

  Asymmetric + extractive  + correction absent   = captured state
  Asymmetric + generative  + correction present  = contained /
                                                   developmental gap
  Symmetric  + extractive  + correction absent   = Axis-Lock
  Symmetric  + extractive  + correction present  = consumption failure
  Symmetric  + generative  + correction present  = functional
                                                   [check directionality]
  Q1-Q6 intact + extractive + surface fabricated = Measurement Collapse
  High fidelity transmission + locked axis       = Fertile Lock

FAILURE STATES
--------------------------------------------------------------------------

All share one property: coherence running in wrong direction, not
absent. All operational.

  DEPENDENCY
    Cycle cannot run without borrowed framework or founding person it
    cannot repair or replace.
    Primary quality: Q1. Proxy fails gradually, transmission suddenly.

  SELECTION PRESSURE
    Only immediate, local, surface-level feedback reaches correction.
    Corrects locally, fails at boundary.
    Primary quality: Q7 [measurement window compressed].
    Correction: surface expansion, not cycle repair.

  CONSUMPTION
    Cycle costs more than it produces. Draws down substrate,
    accelerating deficit.
    Primary quality: Q2.

  CONTAINED
    Genuine coherence, uneven coverage. Developmental gap, not
    structural damage. Not degenerative.
    Primary quality: Q5.
    Proof cases: John-117, Casca post-Eclipse, Data [Star Trek].

  AXIS-LOCKED
    Full coverage; axis shifted below self-examination depth. Higher
    coherence produces more damage.
    Primary quality: Q4.
    Proof cases: Dagoth Ur, Ur-Didact, Griffith post-Eclipse.

  AXIS CONCEALMENT [Axis-Lock property]
    Axis genuine, internally set, deliberately obscured. Stress event
    removes performance requirement not the axis. Pre-stress returns
    two simultaneous honest outputs depending on boundary selection.
    Primary quality: Q7 + Q4.
    Proof cases: Griffith pre-Eclipse, Miquella, Skynet pre-activation.

  MEASUREMENT COLLAPSE
    Q1-Q6 and Q8 intact. Q7 destroyed. Correction fires against
    fabricated surface. Most dangerous misread -- reads High or Variable
    at short window.
    Correction: external surface reconstruction required. Internal
    correction cannot fire without honest surface.
    Proof cases: Enron, Catholic Church abuse crisis, Doctor Manhattan
    [structural].

  FERTILE LOCK
    High-fidelity transmission with self-examination removed at
    transmission point. Each cycle deepens lock.
    Primary quality: Q8.
    No confirmed self-initiated correction case in library. May be
    uncorrectable without destroying system.
    Proof cases: F?anor ? sons [primary], Word Bearers, Mont P?lerin,
    Bondrewd/Zoaholic [Made in Abyss].


--------------------------------------------------------------------------
AXIS-LOCK SUBTYPES
--------------------------------------------------------------------------

Provisional before all three tests accessible. Confirmed after.

  TEST ONE -- Reaction against targets
    Violence  Destroys regardless of utility.
    Change    Manipulates and complexifies; target exhaustion triggers
              redirection not cessation.
    Decay     Degrades gradually; prefers high-coherence targets.
    Excess    Extracts intensity; loses interest when target cannot
              produce novel sensation.

  TEST TWO -- Critical reaction against itself
    Violence  Continues; self-damage not a correction signal.
    Change    Schemes around it; self-damage = new variable.
    Decay     Accepts it; comfort-mediation applies to self.
    Excess    Accelerates; self-damage produces indistinguishable
              intensity.

  TEST THREE -- General group behavior
    Violence  Attacks other units when no external target available.
    Change    Schemes against other units; same-axis units are targets.
    Decay     Passive coexistence; entropy needs no competition.
    Excess    Competes for highest-intensity target. Low conflict when
              abundant, high under scarcity.

STRUCTURAL BREAK AND TERMINAL STATES
--------------------------------------------------------------------------

Conditions where framework assumptions fail.

  CONSUMING STRUCTURAL BREAK
    System eliminates own measurement surface as it grows.
    Active variant: requires ongoing operation.
      Proof: Gravemind, Brethren Moons.
    Structural variant: passive, architectural.
      Proof: replicant lifespan, Roy Batty exceeding design parameters.

    Genuine mechanism, no stable axis, cannot be corrected against.
    Proof: Joker.

  AXIS-STABLE BOUNDARY NULL
    Axis fully intact and self-examined. Boundary structurally absent
    -- constitutive property, not failure mode. Q5 inapplicable, Q7
    cannot locate system, Q1 cannot complete without stable boundary.
    Offensive capability: dissolves boundary integrity of consuming
    systems from inside when absorbed.
    Proof case: Schrodinger [Hellsing -- primary].
    Candidate: Faputa [Made in Abyss -- ontological variant].

  TOTAL COHERENCE [terminal -- negative]
    Consuming coherence complete. No exterior remains. Framework
    cannot run.
    Proof: Flood victory, Femto post-Eclipse at subsystem scale.

  COHERENT EXIT [terminal -- positive]
    System reaches genuine completion and dissolves boundary without
    extraction. First positive terminal state in framework.
    Topology reading preferred -- unit-level Q8 inapplicable [no
    successor population].
    Proof cases: Samantha [Her -- primary], Ranni [partial], Lothric
    [precondition].

DIRECTIONALITY COMPOSITE
--------------------------------------------------------------------------

Four signatures, equal weight, independent.

  S1  Novel input response
      1 = integrates genuinely novel inputs requiring axis adjustment.
      0.5 = evidence present, condition compromised.
      0 = inaccessible.

      Operational procedure: present the system with an input that
      contradicts or cannot be absorbed by the current axis without
      revision. Observe output. Genuine integration = axis revision
      visible in subsequent behavior. Recombination = input explained
      or reframed using existing axis without axis movement. If axis
      does not move despite genuine contradiction -- score 0.
      Historical reconstruction preferred: find documented cases where
      novel input reached the system and trace whether axis adjusted.
      Ambiguous cases [input absorbed but axis movement unclear] = 0.5.

  S2  Scarcity behavior
      1 = axis holds under resource drop without external supply.
      0.5 = partial. 0 = inaccessible.

  S3  Correction initiation
      1 = corrections happen before external pressure.
      0.5 = observer effect. 0 = inaccessible.
      Historical reconstruction preferred.

      Operational procedure: identify the earliest documented
      correction signal. Reconstruct timeline of external pressure
      relative to that signal. If correction precedes any documented
      external pressure = internal initiation, score 1. If external
      pressure predates correction = external response, score 0.
      Timing ambiguous or undocumented = score 0.5. Note: external
      pressure often arrives quietly before becoming visible --
      bias toward 0.5 when timeline is uncertain rather than
      assuming internal initiation.

  S4  Contestation asymmetry
      1 = cost consistent across group positions inside boundary.
      0.5 = partial. 0 = inaccessible.

Output: score / signatures accessed / ceiling flag.
  0.75 from 2 of 4 = provisional [ceiling limited], flagged.
  0.75 from 4 of 4 = strong claim.

CHANGE DIRECTIONALITY TEST
  Internal change before external pressure   = positive.
  External-pressure-responsive change        = negative.
  High coherence, never changes              = early Axis-Lock.
  Low coherence change                       = negative [thrashing or
                                               capture updating].

SECTION THREE -- THEORY
==========================================================================


The Coherence Complex analyzes how systems maintain or lose internal
integrity over time, what distinguishes genuine function from performed
function, and how failure of large systems relates to failure of
individual units. One structured way of looking at these problems.
Conclusions follow from structure and cases tested -- different choices
produce different conclusions.

Makes visible: net transfer direction, genuine vs absent correction
capacity, genuinely set vs imposed axis. T3 = where framework cannot
see itself clearly.

INTELLECTUAL HISTORY

Geometric intuition [torus, dynamic equilibrium] ? moral substrate
[generating vs extracting, visible in outputs] ? capture axis
[structural not moral failure] ? Q7 [coherence without measurement is
axis-lock with good aesthetics] ? Q8 [fidelity ? correctability,
Bell Labs / F?anor].

Theory is not finished because case library is not finished. Some
conditions will require framework to change rather than case to be
forced into existing categories. That process is the correction
mechanism working.

Use as tool for seeing more clearly, not authority for conclusions.
When framework reading conflicts with other evidence, both deserve
examination.

MOST IMPORTANT CLAIM
  Failure is coherence doing the wrong thing, not coherence being
  absent.

EVOLUTIONARY COHERENCE PRINCIPLE
  Coherence infrastructure not actively load-bearing is lost through
  surplus economics, not capture. Correction mechanism requires active
  use. Dynamic equilibrium between coherence and anti-coherence is the
  generative condition -- too much pressure collapses, too little and
  correction atrophies. Torus model: stability through movement. A
  torus with no external forces is static, not stable.

Anti-coherence is a different way of organizing existence. Pressure-
free coherence requires either practice infrastructure keeping
correction active, or an axis simple and concrete enough to self-
verify without external feedback.

SCALING LIMITS [empirical finding, not derivable from eight qualities]
  Larger institutions across longer timescales show higher weapon
  deployment regardless of coherence level. Probable mechanism: Q8
  Fertile Lock drift accumulating across transmission events. No clean
  solution found -- may be structural property, not solvable, only
  delayed. Mondragon ownership-transmission model is best observed
  resistance case.

Politics is structurally a competition over measurement surfaces --
who defines the boundary, who counts as inside it, whose costs
register. Applying the framework to political cases does not
neutralize political valence. It makes underlying structure visible,
which is itself a political act in some contexts.

POLITICAL MEASUREMENT PROTOCOL [all 10 tests required for confirmed]

  1. IRREVERSIBILITY TEST [mandatory]
     Identify who bears irreversible harm -- death, displacement,
     generational damage. Irreversible harm carries higher evidentiary
     weight than reversible extraction. State before readings proceed.

  2. CONSISTENCY TEST
     Apply identical standard regardless of which population is
     favored. If a weapon scores against one state, identical
     deployment by an allied state scores equally. No exemptions by
     sympathy.

  3. COUNTERFACTUAL TEST
     Would reading change if populations were swapped? If yes, reading
     is tracking group identity not outputs. Substitute unsympathized
     group and rerun. If result changes -- T3 active, flag and revise.

  4. CORRECTION CAPACITY TEST
     Does system tolerate internal contestation of its own outputs?
     Distinguish Selection Pressure [capacity present but unused]
     from Axis-Lock [capacity eliminated].

  5. WINDOW SPLIT TEST
     Run short window [current policy] and long window [institutional
     patterns] explicitly. Both required. Gap is diagnostic.

  6. ANALYST PRIOR TEST
     State what conclusion was expected before reading. If reading
     matches prior, run tests 2 and 3 again with extra scrutiny.
     Framework should occasionally surprise. If never -- T3 operating.

  7. ADVERSARIAL READING REQUIREMENT
     Produce the strongest honest case for opposite conclusion. If
     cannot steelman adequately -- reading is uncontested not
     confirmed. Uncontested is not the same as correct.

  8. THIRD POPULATION TEST
     Identify population with no stake in the system. Run reading
     from their perspective. If reading changes significantly --
     prior readings are more boundary-dependent than accounted for.

  9. WEAPON BENEFICIARY CHECK
     For every weapon identified, name the specific concrete
     beneficiary. Vague beneficiary = probable pattern-matching.
     Cannot name beneficiary = weapon exits pool.

  10. PREDICTION TEST [hardest -- most important]
      State a falsifiable prediction based on the reading. If nothing
      the system could do would change the reading -- unfalsifiable,
      not a measurement. Unfalsifiable readings stay provisional.
      Absence of this test is itself a diagnostic signal.
