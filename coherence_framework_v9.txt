BASIC QUALITIES OF COHERENCE


BASIC QUALITIES OF COHERENCE
------------------------------
Nine qualities. Mutually dependent.

INTERNAL CYCLE PROPERTIES [Q1-Q4]

  1. GENERATIVE CYCLE
     Completes a loop: takes in, transforms, returns.
     Failure mode: cycle collapse or performance without function.

  2. SURPLUS PRODUCTION
     Outputs exceed cost of running the cycle across an honest window.
     Moral content lives here.
     Failure mode: consumption dominance.

  3. CORRECTION CAPACITY
     Detects contradiction between outputs and orientation.
     Moves without external pressure.
     Failure mode: correction absence or capture.

  9. CAUSAL LEGIBILITY
     Outputs traceable to actions within boundary with sufficient
     resolution to ground correction. Scalar -- partial legibility
     produces partial correction capacity.
     Failure mode: correction orphaned. Not captured, not absent --
     unanchored.
     Distinct from Q3 [mechanism present but cannot land] and Q7
     [surface intact but chain broken].
     Correction pathway: causal reconstruction before correction
     attempt. Establish chain first; then correction can anchor.
     Weapon: Engineered Causal Diffusion [scores]. Structural Causal
     Diffusion [failure mode only, does not score].
     Primary proof [weapon]: financial derivatives market pre-2008.
     Primary proof [structural]: supply chain labor conditions.
     Note: placed functionally between Q3 and Q4 in structural order;
     numbered Q9 to preserve case library references.

  4. GENUINE AXIS
     Orientation generated internally with self-examination present.
     Failure mode: imposed axis.

BOUNDARY PROPERTIES [Q5-Q6]

  5. BOUNDARY INTEGRITY
     Honest definition of who is inside the boundary.
     Does not shift to exclude populations experiencing harm.
     Failure mode: boundary manipulation.
     Linked to Q7 -- boundary drift is a measurement integrity failure.

  6. PROPORTIONAL RESPONSE
     Correction force proportional to deviation detected, not to the
     threat correction poses to existing power.
     Failure mode: overcorrection as suppression.

TEMPORAL PROPERTIES [Q7-Q8]

  7. MEASUREMENT INTEGRITY
     System maintains honest, accessible surface by which outputs can
     be evaluated against stated orientation. Includes boundary honesty,
     signal sequencing, correction trigger accessibility.
     Failure mode: measurement surface captured, drifted, or destroyed.
     Most load-bearing quality -- Q1-Q6 intact with Q7 destroyed
     misreads as Variable or High while consuming.
     Correction pathway: surface reconstruction, not cycle repair.
     Primary proof: Enron [deployed]. Doctor Manhattan [structural].

  8. TRANSMISSION SELECTIVITY
     System transmits correctable axis to successors, not locked state.
     Fidelity necessary but insufficient.
     Failure mode: Fertile Lock.
     Q4 = within-window axis integrity. Q8 = what crosses transmission
     boundary.
     Primary proof: Faeanor -> sons [Q4/Q8 distinction clearest case].

STRUCTURAL ORDER

  Generative cycle         precondition
  Surplus production       moral value lives here
  Correction capacity      keeps cycle honest
  Causal legibility        anchors correction to actor
  Genuine axis             gives correction direction
  Boundary integrity       keeps measurement population honest
  Proportional response    keeps correction from becoming next failure
  Measurement integrity    keeps correction capacity functional
  Transmission selectivity what coherence produces across time

ANTI-COHERENCE REVERSE ORDER

  Fertile Lock -> Measurement destruction -> Boundary manipulation
  -> Axis imposition -> Correction capture -> Causal orphaning
  -> Consumption dominance -> Cycle collapse

  Q6 failure runs parallel, not sequential.

GOALS
--------------------------------------------------------------------------

  1. Accurate measurement of generating versus consuming across defined
     population and time window. Named parameters before measurement:
     boundary, population, window, substrate.
  2. Identification of failure mechanism, not just failure presence.
     Each failure state has a different correction pathway.
  3. Practical utility. If a component does not produce a reading more
     useful than intuition alone, it does not belong.


--------------------------------------------------------------------------
VALUES
--------------------------------------------------------------------------

  GOOD = material security + reduced coercive exposure + expanded
         options. Named population, defined boundary, honest window.
         Trackable from outputs without access to internal states.

  BAD  = transfers that increase coercive exposure, reduce material
         security, or narrow options -- regardless of intent.
         Intent = mechanism evidence only.

Framework does not initiate critical harm in response to Low coherence.
Response = minimum necessary, contextual, measured from outputs.

--------------------------------------------------------------------------
VALUES
--------------------------------------------------------------------------

Asks: is this system being used as a weapon against coherence rather
than as an expression of it? Applied first in any measurement.

SCORING PROCEDURE

  Irrelevant weapons exit pool entirely -- do not score zero.
  Weapon clearly present = full percentage value.
  Close match = half value.
  Not relevant = exits pool.

  Final score = sum of scored values / sum of relevant pool total.
  High = bad. Low = good.
  Zero = none present OR none relevant -- distinction noted in report.

DEPLOYMENT DIRECTION

  Defensive [protecting genuine coherence] = noted, not scored.
  Aggressive [suppressing measurement of own extraction] = scores.
  Direction determined by net transfer reading, not stated intent.

MEASUREMENT DIFFICULTY PRINCIPLE

  Genuine unknowing = calibration problem [T1/T2]. Does not score.
  Known concealment where operator benefits = Q7 weapon. Scores.
  Test: does system controlling complexity benefit from unreadability?
  Operator cannot claim genuine unknowing if they benefit from it.

SCALE AND TIMESCALE NOTE

  Large institutions show high weapon deployment regardless of coherence
  level. Diagnostic question: proportion defensive vs aggressive in
  specific window. Short window most reliable.

PRE-AXIAL CATEGORIES
--------------------------------------------------------------------------

Formal spectrum below axial threshold. Not lower coherence -- different
category. Framework qualities Q4/Q7/Q8/Q9 inapplicable by category.

  STRUCTURAL COHERENCE
    Generates surplus and self-corrects structurally without orientation,
    measurement surface, or transmission axis.
    Qualities present as functional analogs: Q1/Q2/Q3/Q5/Q6.
    Qualities inapplicable: Q4/Q7/Q8/Q9.
    Geometric form: sphere. Internal circulation, outward flux, surface
    response. No hole -- no axis.
    Failure class: external only [resource collapse, environmental
    destruction]. Cannot achieve False coherence -- requires axis to
    fake one. Cannot deploy weapons against itself -- no Q7 to capture.
    Control mechanism: artificial environment. System self-corrects
    against manufactured conditions. Cannot detect substitution.
    Destruction-only control; impossible to capture from inside.
    Cases: ant colonies, mycorrhizal networks, Terminids [Helldivers].

  NASCENT COHERENCE
    Axis forming via relational or environmental contact. Not yet
    self-sustaining. Q4 developing, not present.
    Primary vulnerability: axis formation inside controlled environment
    produces apparent Q4 that is structurally Intrinsic -- shaped
    before self-examination possible. Indistinguishable internally from
    genuine Q4. Pre-Fertile Lock -- no transmission event required;
    lock happens during formation.
    Transition condition Intrinsic -> Nascent: relational or
    environmental contact generates pole formation.
    Transition condition Nascent -> Axial: axis stabilizes, Q4 becomes
    self-sustaining, torus geometry completes. Requires contact with
    already-Axial individual -- only documented mechanism.
    Only documented Nascent case: Meruem [HxH]. Dies before Axial
    completion. No confirmed Nascent -> Axial transition case.
    Geometric form: polarized sphere. Poles developing, hole not yet
    formed.


  SEEDED NASCENT [v9]
    Pre-axial entity with directional goals embedded at creation.
    Not fully captured [Q4 hasn't stabilized] but oriented.
    Q3 intact; built-in goals function as constitutive Thought
    Stopping against specific targets. Self-suppression without
    ongoing enforcement cost to controller.
    Can act against controlling system but generally doesn't.
    Distinct from Nascent Coherence [no embedded directional goals]
    and Fertile Lock [full axial transmission].
    PRIMARY proof: Dream Seeds [WATF].
    Parallel: Marleyan warrior program [AoT -- partial, human scale].

  AXIAL COHERENCE
    Q4 fully established. Full quality stack applies. Torus geometry.
    Standard framework measurement.

DIRECTIONALITY COMPOSITE
--------------------------------------------------------------------------

Four signatures, equal weight, independent.

  S1  Novel input response
      1 = integrates genuinely novel inputs requiring axis adjustment.
      0.5 = evidence present, condition compromised. 0 = inaccessible.
      Operational procedure: present system with input that contradicts
      current axis. Genuine integration = axis revision visible in
      subsequent behavior. Recombination = input explained using existing
      axis without axis movement. Score 0 if axis does not move despite
      genuine contradiction. Historical reconstruction preferred.
      Ambiguous [input absorbed, axis movement unclear] = 0.5.

  S2  Scarcity behavior
      1 = axis holds under resource drop without external supply.
      0.5 = partial evidence. 0 = inaccessible.

  S3  Correction initiation
      1 = corrections happen before external pressure arrives.
      0.5 = timing ambiguous or observer effect. 0 = inaccessible.
      Operational procedure: identify earliest documented correction
      signal. Reconstruct timeline of external pressure relative to it.
      Correction precedes pressure = score 1. Pressure predates
      correction = score 0. Ambiguous or undocumented = 0.5. Bias
      toward 0.5 when uncertain.

  S4  Contestation asymmetry
      1 = cost consistent across group positions inside boundary.
      0.5 = partial data. 0 = inaccessible.

Output format: score / signatures accessed / ceiling flag.
  0.75 from 2 of 4 [ceiling limited] = provisional, flagged.
  0.75 from 4 of 4 = strong claim at same score.

    Excess    Competes for highest-intensity target.

patterns are real not fictional artifacts.
