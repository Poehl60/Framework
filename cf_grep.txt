KIT FILE GRAMMAR [v25 -- all main txt; division / topic / content loop]
==========================================================================
Universal shape. Same loop in theory, applied, cases, wip.

  FILE     ::= file-header + DIVISION*
  DIVISION ::= division-banner + division-meta* + TOPIC* + [end-banner]
  TOPIC    ::= topic-title + topic-rule + CONTENT
  CONTENT  ::= body [shape per file below] + optional footer

  Delimiters:
    File / division banner:  ========  [full-width line]
    Topic rule:              -------- or ---------- [legacy; under title]
    Case topic-title:        ^[CASE:NAME]
    WIP topic-title:         ^WIP N:

    indexes, queues, SESSION START, STATUS INDEX, ACTIONABLE QUEUE.

  Loop rule: repeat TOPIC until next division-banner or EOF / end-banner.
  Add rule: grep file for topic keyword -> extend existing TOPIC;
    new TOPIC only for new home. One primary file per promote task.
