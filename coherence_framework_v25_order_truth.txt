ORDER TOWARD TRUTH [named distinction -- v25]
--------------------------------------------------------------------------------------------------------------------------------------------
  Order is good only as orientation toward truth [legible, correctable structure]. Order that serves a
  person, formation, or nation is loyalty architecture wearing a rulebook -- not truth contact.
  Telos test:
    Beneficiary-order: rules fire to protect THIS actor or THIS unit [stability, punishment of threats
      to us, cohesion, loyalty reward]. Legitimacy surface / imposed axis / partial state religion class.
    Truth-order: rules fire to make structure legible and correctable -- CAUSAL LEGIBILITY, MEASUREMENT
      INTEGRITY, behavioral record over stated position. Oriented toward TRUTH AXIS contact via four
      conditions [tests not badges].
  THREE ORDER TYPES [political psychology routing]:
    GENERATIVE ORDER: order toward truth + correction + surplus flow outward. Rules hold tension;
      routing traceable; break captured order when contact blocks. Material surplus legitimate only
      here -- landing, not loyalty reward.
    PUNITIVE ORDER: hostility through rule-enforcement mask [tradition, obedience, punish deviance].
      RWA-class bridge [Otoni et al. 2026 PAID DOI 10.1016/j.paid.2026.113688]: D-factor antagonism
      routes to self-control entirely through right-wing authoritarianism, not SDO hierarchy -- order as
      punitive costume serving the bridger, not truth or fair distribution.
    COMPLIANCE ORDER: hostility through moral/conformance mask [cancellation, virtue enforcement,
      "our side" policing]. LWA / dark-ego-vehicle class adjacent [not identical to RWA sample]. Stated
      anti-hierarchy can still be beneficiary-order.
  Distinctions load-bearing:
    ROUTING [who gets surplus] ≠ ORDER TYPE ≠ CORRECTION [break/fix when order blocks contact].
    Marx praxis read [11th Thesis]: change the world = doing over yap; not order for a class beneficiary.
  Falsification: beneficiary-order consistently produces higher CAUSAL LEGIBILITY and correction access
    than truth-order when both are tested on same substrate.
  Cross-ref [QC pointer only]: coherence_framework_v25_ABSTRACT.txt REALITY
    STACK -- Order goal ≠ absolute good; costly good/bad tolerated;
    extraction among few hard nevers; costless good ≈ disorder/stupid;
    honesty required on high-complexity / exit paths [PERSONAL BIAS;
    not kit finding].
